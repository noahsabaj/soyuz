# API Reference

The API reference is generated from `docs/api/manifest.toml`.

## Categories

- Primitives: shape constructors.
- Operations: boolean operations and blends.
- Modifiers: shell, round, deformation, and repetition methods.
- Transforms: translation, rotation, scale, mirror, and symmetry methods.
- Math helpers: angle conversion and constants.
- Environment: lighting, material, sky, fog, effects, and presets.

The same source generates the website API manifest, MCP discovery data, and Rhai registration glue used by `ScriptEngine`.
